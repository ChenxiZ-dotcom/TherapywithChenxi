## 1. Contact form (connected)

Submit a test message once the site is live and confirm it reaches your email.

If you use a different form service, replace the whole `action="..."` address with the one it gives you.

## 2. Put it on GitHub Pages
1. On github.com, create a new public repository (for example `chenxi-counseling`).
2. Click "uploading an existing file" and drag in `index.html`, `README.md`, and the `images` folder.
3. Click "Commit changes".
4. Go to Settings > Pages. Under "Branch," choose `main` and `/ (root)`, then Save.
5. After a minute or two, your site is live at `https://YOUR-USERNAME.github.io/chenxi-counseling/`.

## 3. Optional: your own domain
Buy a domain (for example chenxizhucounseling.com), then add it under Settings > Pages > Custom domain and follow GitHub's DNS instructions. Turn on "Enforce HTTPS."

## 4. Making changes later
Edit `index.html` directly on GitHub (pencil icon), then commit. The site updates in a minute or two.

## 5. Search and sharing tags (done)
All pages, the sitemap, and robots.txt already use https://therapywithchenxi.com. The CNAME file tells GitHub Pages your custom domain.
